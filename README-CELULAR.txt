PATSY FINANCE V10 — versión instalable como app web (PWA)

Archivos:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

IMPORTANTE: para que el botón "Agregar a pantalla de inicio" funcione como PWA, los archivos deben abrirse desde un sitio HTTPS (no directamente como archivo local).

Una forma sencilla es subir esta carpeta a un hosting estático HTTPS. Si se abre localmente, la V10 sigue funcionando como página HTML, pero no tendrá todas las funciones de instalación PWA.
